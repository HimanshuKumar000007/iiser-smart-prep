1. Core Concept

Measurement & Dimensional Analysis

Measurement: Expressing a physical quantity (Q) as numerical value (n) × unit (u). The magnitude remains constant across different systems of units:

n1u1 = n2u2 ⟹ n ∝ 1/u

Dimensional Analysis: Representing physical quantities in base dimensions [M, L, T, A, K, mol, cd] to check equation consistency or derive formulas.

Significant Figures

Significant Figures represent the reliable digits plus the first uncertain digit in a measurement. They indicate the precision of the measuring instrument used.

2. Key Formulas & Error Propagation

Principle of Homogeneity

You can only add or subtract quantities with the identical dimensions.

If A = B + C - D
Dimensions must match: [A] = [B] = [C] = [D]

Error Propagation (Most Important)

The golden rule of error analysis: Errors ALWAYS add up to maximize the possible error.

If Z = A ± B ⟹ ΔZ = ΔA + ΔB
For addition or subtraction, Absolute Errors always add.
If Z = AxBy/Cz ⟹ ΔZ/Z = x(ΔA/A) + y(ΔB/B) + z(ΔC/C)
For multiplication or division, Fractional/Percentage Errors add, multiplied by their powers.

Measuring Instruments

Instrument Least Count (LC) Formula Key Terminology
Vernier Calliper 1 MSD − 1 VSD Main Scale Division minus Vernier Scale Division
Screw Gauge Pitch / Total Circular Divisions Pitch = distance moved in 1 full rotation

True Reading Rule: True Reading = Measured Value − Zero Error (Make sure to include the proper sign of the zero error!).

4. Conceptual Insights

Dimensionless vs. Unitless

A dimensionless quantity can have a unit. For example, Plane Angle has dimensions [M0 L0 T0] but its unit is Radians. However, a unitless quantity is always dimensionless (e.g., Refractive Index, Strain, Relative Density).

Math Functions

The arguments of trigonometric functions (sin(θ)), logarithmic functions (ln(x)), and exponential functions (ekx) must be strictly dimensionless [M0 L0 T0]. The functions themselves evaluate to pure numbers, meaning they are also dimensionless.

Rounding Rule for '5'

When dropping digits to obtain proper significant figures, what if the exact digit to drop is a 5?

  • Look at the preceding digit.
  • If the preceding digit is even, leave it alone (e.g., 2.45 → 2.4).
  • If the preceding digit is odd, round it up (e.g., 2.35 → 2.4).

5. Common Mistakes

⚠️

Trap 1: Subtracting Errors in Subtraction

If Z = A − B, students often mistakenly write ΔZ = ΔA − ΔB. TRAP! Errors always compound to find the maximum possible uncertainty. The correct formula is always ΔZ = ΔA + ΔB.

⚠️

Trap 2: Mixing up Sig Fig Rules

Addition/Subtraction: The result has the same number of decimal places as the term with the fewest decimal places. (e.g., 10.1 + 1.02 = 11.1, NOT 11.12).

Multiplication/Division: The result has the same total number of significant figures as the term with the fewest significant figures.

⚠️

Trap 3: Zero Error Signs

Remember how zero errors are treated: A Positive zero error must be subtracted from the reading. A Negative zero error must be added to the reading.

6. Example Applications

(P + a/V2)(V - b) = RT
Van der Waals Equation Dimensional Analysis

Insight: By the Principle of Homogeneity, since a/V2 is added to pressure P, it must have the dimensions of Pressure.
[a] = [P][V]2 =[M L-1 T-2] × [L3]2 = [M L5 T-2].
Similarly, b is subtracted from volume V, so it must have dimensions of volume: [b] = [L3].

Error in calculating Gravity (g) using a Simple Pendulum

Formula: T = 2π√(L/g) ⟹ g = 4π2L/T2

Insight: To find the percentage error in g, we apply the propagation rule:
(Δg/g)% = (ΔL/L)% + 2(ΔT/T)%.
Note: Exact constants like 4π2 have zero error and do not appear in the error equation.

7. IAT Exam Focus Points

Non-standard Base Quantities (Time Saver Trick)

IAT loves asking: "If Force (F), Velocity (V), and Time (T) are taken as fundamental quantities, find the dimension of Mass."

Shortcut: Don't use the long method of setting M ∝ FaVbTc and solving 3 equations! Just use basic physics formulas to relate them directly:

F = ma ⟹ F = m(V/T) ⟹ m = FT/V ⟹[F1 V-1 T1]

Electromagnetic - Mechanic Analogs (Memorize these!)

Dimension Electromagnetic Combinations
Time [T] L/R,   RC,   √(LC)
Velocity [L T-1] E/B,   1/√(μ₀ε₀)
Energy Density / Pressure [M L-1 T-2] ½ε₀E2,   B2/(2μ₀)

Maximum Percentage Error Rule

In questions asking to minimize or calculate the maximum percentage error of an expression like X = A2 B3 C1/2, remember that the quantity with the highest power (here, B with a power of 3) dictates the precision required. To minimize the overall error in X, you must measure B most accurately.

Matching Quantities

Questions frequently ask to identify pairs with identical dimensions. Keep these common pairs in mind:

Identical Dimension Physical Quantities
[M L T-1] Impulse & Momentum
[M L2 T-1] Angular Momentum & Planck's Constant
[T-1] Frequency, Angular Velocity, Velocity Gradient, Decay Constant
