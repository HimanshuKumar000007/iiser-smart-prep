1. Core Concept

What is Kinematics?

Kinematics is the branch of mechanics focused on describing how things move (position, velocity, acceleration), without worrying about why they move (forces/mass).

📏

Distance vs. Displacement

What's the difference?

Tap to reveal

Distance: Actual path length (Scalar). Always ≥ 0, never decreases.

Displacement: Shortest vector from Initial → Final position.

Distance ≥ |Displacement|

⏱️

Average vs. Instantaneous

Secant vs Tangent

Tap to reveal

Average: Calculated over a time interval Δt. Represents the secant line on a graph.

Instantaneous: Calculated at an exact moment (dt → 0). Represents the tangent line.

2. Key Formulas (Calculus & Algebra)

The Calculus Triangle (Universal)

These definitions work for both constant and variable acceleration.

v = dx/dt
a = dv/dt = d²x/dt²
a = v(dv/dx)
CRITICAL: Use a = v(dv/dx) when acceleration is given as a function of position (x), not time (t)!

Kinematic Equations (Algebra)

STRICTLY use these when Acceleration (a) is CONSTANT.

v = u + at
s = ut + ½at²
v² = u² + 2as
sn = u + (a/2)(2n - 1)
Note: sn is the displacement strictly in the nth second.

3. Important Shortcuts & Memory Tricks

Time-saving derivations that show up constantly in competitive exams.

Mid-Point Velocity

If a body moving with constant acceleration has velocity v₁ at point A and v₂ at point B, its velocity exactly at the midpoint of distance AB is:

vmid = √[ (v₁² + v₂²) / 2 ]

Average Speed Tricks (For 2 parts)

  • Equal Distances: vavg = 2v₁v₂ / (v₁ + v₂) (Harmonic Mean).
  • Equal Times: vavg = (v₁ + v₂) / 2 (Arithmetic Mean).

Stopping Distance (x)

When brakes cause a constant retardation a, the stopping distance is:

x = u² / 2a

Trick: Since x ∝ u², if you triple the initial speed (u), the braking distance becomes 9 times longer!

Galileo's Law of Odd Numbers

For a body dropped from rest (u = 0) under constant acceleration (a):

  • Distances fallen in successive equal time intervals: 1 : 3 : 5 : 7...
  • Times taken to fall successive equal distances: 1 : (√2 - 1) : (√3 - √2)...

5. Common Traps & Mistakes

⚠️

Trap 1: The Calculus Distance Trap

If asked for Distance using v(t) = 2t - 4 from t = 0 to t = 4, you CANNOT just integrate from 0 to 4.

The Trap: ∫ (2t - 4) dt from 0 to 4 = 0. This calculates Displacement, not Distance!

The Fix: Find where v = 0 (at t = 2). Split the integral:
| ∫ v dt (0 to 2) | + | ∫ v dt (2 to 4) | = |-4| + |4| = 8 m.

⚠️

Trap 2: Applying (v = u + at) to Variable Acceleration

If acceleration depends on time or position (e.g., a = 3t or a = -kx), the standard kinematic equations collapse entirely. You MUST use integration.

⚠️

Trap 3: Impossible Graphs & Highest Point

  • Time never goes backward. Any graph that curves back on the x-axis (if x is time) is physically impossible.
  • Sharp points/corners in an x-t graph imply infinite acceleration (impossible in reality).
  • Throwing a ball up: At the highest point, v = 0, but a ≠ 0 (acceleration is still 'g' downwards).

6. Example Applications

Finding Max/Min Velocity

Problem: Given position x = t³ - 6t² + 9t. When is velocity minimum?

Insight: First, find velocity: v = dx/dt = 3t² - 12t + 9. To minimize v, you must set its derivative (acceleration) to 0.
a = dv/dt = 6t - 12 = 0 ⟹ t = 2 seconds.

Reaction Time Crash Problem

Problem: Driver traveling at speed u sees a hazard. Their reaction time is tr, after which they brake with retardation a.

Insight: Total stopping distance is the sum of the distance covered while reacting (constant speed) and braking (decelerating).
Total Distance = utr + (u² / 2a)

7. IAT Exam Focus Points

Quick Recap / Short Notes

IAT questions heavily favor Calculus over Algebra. Always check if $a$ is constant before using formulas. For 1D collisions/overtaking, Relative Velocity is your fastest tool.

Differentiation/Integration Heavy

IAT strongly tests your ability to link x, v, and a using calculus. Get very comfortable with integrating with limits. For example, moving from v(dv/dx) = a to:

v·dv = a·dx ⟹ ∫ v·dv (from u to v) = ∫ a·dx (from 0 to x)

Turning Points (U-Turns)

A particle reverses direction ONLY when v = 0 AND acceleration is non-zero. If the IAT asks for "Total distance covered in 5 seconds", immediately check if v = 0 happens between t = 0 and t = 5. If it does, you must split the calculation to account for the U-turn.

Relative Velocity in 1D

For problems like "Train A overtaking Train B": Always freeze one object to simplify the frame.

  • Set vrelative = vA - vB
  • Set arelative = aA - aB
  • Distance required to overtake: Srel = Sum of their lengths

Then apply the standard kinematic equations using only these relative values.
